■Terrain


  • WWall
    • Standard wall tile. Blocks movement.
  • SStep Tile
    • Item like tile. Destroyed upon stepping on.
  • BBreak
    • Like a wall but breaks when hit.
  • PPush
    • Can be pushed by player and objects
  • AAnimation Tile
    • Efficient animation tile. Pre-rendered and can't be changed by objects without destroying.
  • IInvisible Wall
    • Blocks player and objects but not bullets.

♦Items


  • CCoin
    • Standard currency item.
  • AAmmo
    • Standard ammo item.
  • KKey
    • Key for unlocking same color door.
  • DDoor
    • Standard door item. Can be opened by player.
  • PPassage
    • Move to another board. Use same color to dictate where player appears.
  • ISign
    • Enter text to display when touched. Use <page> to force pagination. Accepts some html (br, em, strong, b, i, center)
